## Критические сценарии для проверки
1. **Двойное принятие**: два водителя принимают один заказ одновременно
2. **Потеря заказа**: клиент отменяет пока водитель едет
3. **isCancel ложное срабатывание**: "нет водителей?" не должно отменять заказ
4. **Голос в любом состоянии**: voice message в waiting_driver, confirming, in_trip
5. **"домой" без сохранённого адреса**: должна быть подсказка, не заказ
6. **Ночной тариф**: в 23:00 и 06:59 — правильная цена?
7. **Межгород**: "в Астану" → intercity флоу, не обычный заказ
8. **Водитель как клиент**: driver_as_client флоу полностью
9. **Таймаут водителя**: 60 сек → автоматический пропуск
10. **Зависший заказ**: >10 мин в searching → автоотмена

## Edge cases которые ломались раньше
- `"к другу на Целиную 10"` → должен нормализовать адрес (не показывать сырой текст)
- `"нет водителей?"` → не должно отменять заказ (`isCancel` exact match)
- `"автостоп"` → не должно отменять подтверждение
- Голосовое "погода" → показать реальную погоду, не выдумывать
- `is_saved_place: "none"` → не падать с ошибкой валидации Groq
